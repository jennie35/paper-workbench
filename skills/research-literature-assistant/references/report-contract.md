# 十一部分研究报告契约

从同一份已检查的来源、证据和行动记录生成笔记、evidence.json 与看板。下列十一部分是分析逻辑，不要求输出空章节：报告只显示实际可分析内容，省略空字段、无内容的可选部分及逐项“未报告/未核验”占位。内部证据记录可保留空值与覆盖状态。用简短的阅读依据和状态说明实际来源；影响结论强度的限制随具体判断说明，不能通过隐藏空项制造完整精读印象。完整精读仍需要相关正文覆盖及决定核心判断的实际原图/表格/公式核对。

## 1. 题录与阅读范围

列已核实的作者、完整标题、期刊/会议、版本、DOI/原文链接、首次发表日期、卷期年份、来源和分析日期；有日期精度差异或冲突时说明。只列实际取得的摘要、网页正文、PDF、补充材料或代码及实际读取、图像查看范围，来源映射保留指纹和版本。没有的可选题录项不列空行；内部区分原文未报告与分析者没查到。

## 2. 论文总结

一段说明问题、方法、作者报告的主要发现和最重要适用边界。已取得足够文字时先给简明概况，再继续细节；不能用摘要复述代替研究报告。

## 3. 科学问题与研究主线

现象 → 现有方法缺口 → 核心假设 → 设计/测量 → 结果 → 结论。区分作者明确问题与分析者重建的问题；作者没有说明的动机不能改写为作者事实。

## 4. 研究流程示意

用 SVG 或能离线显示的清楚示意图表达对象/输入 → 操作/建模 → 测量/分析 → 输出 → 验证。标注“分析者绘制，非论文原图”。只画作者报告的已实施研究；后续建议另列，不能画成已完成实验。不要把助手检索/读摘要流程冒充论文的研究设计。

## 5. 重建研究设计

根据论文类型选择适用检查，不能把未知信息补造成实验：

| 类型 | 核查内容 |
| --- | --- |
| 实验 | 变量、样本、独立实验单位、设备、参数、对照、随机化、盲法、技术/生物/制造重复层级、排除规则与统计方法 |
| 方法 | 输入输出、基线公平性、训练/测试划分、数据泄漏、消融及外部验证 |
| 理论 | 假设、定义、推导、关键命题、适用条件、反例与证明边界 |
| 综述 | 检索范围、筛选、证据分类、偏倚、异质性和综述类型；不当作新增实验或未实施的荟萃分析 |

只输出有来源支持的设计项目，不逐项填“原文未报告”或“尚未核验”。未知信息可在内部记录为空及对应状态；若它直接限制当前判断，用一句具体的证据边界说明影响，避免将“没查到”等同“作者没做”。

## 6. 关键设计决策

记录选择、解决的问题、理由、理由来源、代价、替代方案和可能影响。归因作者的理由必须有原文定位；根据设计推断的好处标为分析者重建。

## 7. 精选原图、表格与公式核验

挑选直接支撑核心结论、暴露边界或影响课题决策的实际证据。此节仅报告已实际查看、完成解释且具有查看记录的真实图/表/公式；展示来源图像、原文页码及编号/面板、来源指纹和查看记录引用。未核验、模糊或缺少具体内容的项不在此节报告或分析；全部不合格时省略整节。只有文字来源时可在文字证据范围内分析，不能以文字模型的声明代替目视核验。取得、渲染和实际查看分开记录，图像输入工具不可用时不能标已核验。模型目视分析注明“未经人工复核”，保存记录不等于科学结论已被独立证实。

解释比较对象、面板、坐标、单位、统计单位、误差条含义、效应大小和不确定性；核对正文、图注、表格与公式是否一致。关键公式解释目的、符号、单位、被测量、运算直觉、适用条件和限制。分开原文转录、变形和分析者推导；不清楚的符号保留原截图与缺口，不猜。

## 8. 结论、证据与局限

分开作者结果、作者解释、分析者推断和未验证假设，使用真实来源定位建立结论—证据关系。原文冲突保留双方信息及影响，不替作者修正。重点检查：

用简洁的证据→判断→待执行行动关系图帮助阅读，仅连接保存记录中明确关联的 E/C/A ID；允许明确的 E→A 关系，无关联则省略。研究流程图与关系图均注明“分析者绘制，非论文原图”。图示不能将后续建议画成作者已完成的实验，也不能把缺失数值补成统计图。

- 技术重复/独立样本，制造波动/测量重复性，均值区间/单件不确定度。
- 相关/因果，数值改善/统计显著，未显著/等效。
- 模拟或渲染/实测，名义或参考值/物理真值，训练表现/独立泛化。

## 9. 需要重点精读的部分

只列已确认的章节、图、表、公式、实验细节或代码位置。每项说明精读原因，以及会改变哪项研究判断；不生成“位置未定位”的空项，也不猜测位置。

## 10. 未来研究启示

先用一段“对本课题的参考借鉴”供文献卡片直接展示：论文中借鉴什么方法、变量或设计 → 用在本课题哪个具体环节 → 如何调整或验证 → 依据及适用条件。它回答论文怎样帮助本课题，不用题目相似性或取得全文的待办代替。标明分析者建议与作者发现的区别，不把推定设备、参数和资源当作用户已有条件。再说明新解释、方法或变量怎样改变本课题判断；分开有依据的可直接借鉴、需要修改验证及目前不宜迁移的内容和原因。旧记录仅复用已保存的迁移分析；默认占位句不能当分析成果，没有内容时省略。补充实际适用的迁移条件与复现检查，不补造关联。

## 11. 下一步研究规划与行动卡

每篇至少一项具体、待执行且有依据的行动。按实际可制定内容列稳定 A ID、关联 C/E ID、待回答问题、可否定假设、数据和独立单位、方法、基线/对照、混杂控制、支持与削弱方向、判断依据、资源/前置条件、优先级、交付物及停止条件；缺少的可选字段不列占位。样本量、阈值、允许误差引用实际依据，否则将先导估计列为前置方法，不能随意指定 n、改善比例或 p 值。证据不足优先制定取得决定性证据的行动；不得为了卡片数编造实验。路线图引用 A ID，按依赖与信息价值安排，不重复全文。

## 外部阅读技能和数据

已应用 Norman 时，以安装版本的 evidence schema、extend 必需部分、平台引擎命令与验证器为准；保存其原生 evidence.json，不为索引方便破坏其格式。用独立 metadata.json 表示本助手的题录/课题关联/核验范围/索引摘要。外部技能必需的迁移条件、复现清单和路线图应在本报告相应部分保留；遇到用户显式结构要求时按用户结构组织，并说明任何结构验证不兼容，不能伪报校验通过。

未应用 Norman 时使用自己明确标注的记录格式和来源映射，不能套用“已通过 Norman”或其完成署名。读取具体外部技能才确认其当前署名要求；本仓库不再分发第三方技能内容、引擎、资产或许可。


## 正文完成与关系图谱

只有实际阅读正文，并对问题、方法或论证及关键结果保存来源定位，才计新增正文报告。关键结论依赖的图表或公式必须实际查看；未完成时保留处理中记录。摘要、导入及原编号补读不计新增。可视化区分引用、共同参考文献、共同被引和计算的主题相似性，关系保留来源、时间、算法及覆盖范围。行动只引用明确支持的证据子集，禁止自动全连接。
