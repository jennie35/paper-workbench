# 在在线网页直连模型 API

打开[在线看板](https://jennie35.github.io/paper-workbench/)，即可检索文献，并依据实际取得的论文文字生成研究报告，不需要部署私人后台。报告会区分全文文字与摘要；原图、公式和外部阅读技能的核验状态单独保留。

## 填写连接信息

1. 打开连接入口，选择默认的「API 直连」。
2. 填写供应商提供的 **HTTPS API 基础地址**。DeepSeek 官方地址为 `https://api.deepseek.com`，不要手动添加 `/chat/completions`。
3. 填写这家供应商的 **API 密钥**与当前可用的 **文本模型名称**。密钥不等于模型名，也不是 GitHub 或后台登录口令。
4. 可使用获取模型列表功能选择名称；供应商不提供该接口或浏览器无法读取列表时，从供应商控制台复制准确名称，手动填写。项目不固定某个旧模型名。
5. 创建或打开课题，可添加参考 PDF，再填写科学问题、研究阶段、对象、已有方法、真实资源和约束、中英文关键词及排除范围。未知条件留空，不默认具备论文所用的设备。每批默认目标新增 5 篇，可选 1–20；参考 PDF 不占论文额度。
6. 可通过顶部「保存目录」授权唯一长期主目录；未选择前，内容只是当前站点的浏览器草稿。启动前确认范围、数量、模型，以及单篇与跨论文综合会发送的资料。

接口采用兼容的 Chat Completions 请求格式。调用由供应商计费；保存连接信息不运行分析，获取模型列表也不表示已经完成分析。检索后的题录、摘要或已取得的论文文字会连同课题范围发送给指定模型。点击模型提取范围时，还会发送本机实际提取且有长度上限的参考 PDF 文本。

## 添加范围参考 PDF

创建课题或编辑研究范围时，可选择「添加范围参考 PDF」。每份最大 50 MB、300 页，同一课题按 SHA-256 文件指纹去重。PDF 在当前浏览器本机解析，添加文件本身不调用模型，也不将原 PDF 上传至项目服务器或模型供应商。

原 PDF 不持久保存；提取文字、文件名、页数、指纹及读取缺口保存在当前研究库中，绑定目录后随该目录保存。刷新后可查看已保存的提取资料，不代表原 PDF 已保存。同一文件用于不同课题时，各课题分别保存关联资料。

纯扫描 PDF 需要先做 OCR；加密 PDF 不接受处理。混合图文 PDF 若有页面无法提取文字，会记录未读页及缺口。文字提取不能还原原图、公式或可靠判断复杂版式，需自行核对资料。

点击模型提取研究范围后，系统把课题信息与参考资料实际提取的文本发送给配置的模型，可能产生 API 费用。单次请求总计最多发送 60,000 字符；多个参考文件共享额度，超出部分与未发送页明确记录。模型返回的是待确认范围，请修改并保存后再运行检索。

参考 PDF 只作为范围资料。添加参考文字不会将该 PDF 登记为已分析论文，不增加报告篇数，也不表示执行了 Norman 技能、全文精读或视觉核验。

## 一次运行后的报告

进入课题即可并排浏览方块报告卡片，每张先显示主要内容和“对本课题的参考借鉴”，点击后查看详细分析。使用「最近更新」「全部文献」「精选精读」「下一步研究」切换内容。批次选择器和报告标明 `B001` 等课题内顺序号及短任务 ID，批次显示“目标新增 x 篇”和实际新增数；展开运行记录可查看时间、进度和错误。候选及排除理由作为原始审计记录保留，不与报告卡片混排。页面不设置复用或缺额计数块。

每篇按十一类研究内容组织：阅读范围、总结、科学问题、分析者流程、分类研究设计、设计决策、图表公式核验、证据与局限、精读位置、未来启示及待执行行动。只展示能从资料分析得到的字段和章节，省略空项与纯缺失占位；开头保留简要的实际阅读范围和核验状态。已提出的行动保留独立单位、对照、混杂控制、判断依据、资源前提与停止条件等有效内容；无样本量或阈值依据时先做先导估计。完整约定见[研究工作流](RESEARCH.md)。

批次在单篇报告后尝试跨论文综合，比较本课题已有报告的支持、冲突、判断变化和优先行动；不足两篇时不编造跨论文关系。综合失败不删除单篇成果，需手动确认后重试；重新打开页面或切换视图不会触发付费模型调用。按需打开运行简报，可复制或导出目标新增、实际新增、累计、论文概况、精读证据和启示。

检索结合 Crossref 与 OpenAlex。系统按 DOI 合并来源，尝试为缺摘要或缺开放 PDF 链接的论文补充资料，并优先获取允许浏览器读取的开放 PDF。下载文字须匹配 DOI 或论文标题，才可用于全文文字报告。

- **全文文字报告**：依据已取得并实际发送给模型的 PDF 提取文字；保留页码、来源、文件指纹、未读页和上下文截断信息。
- **摘要研究报告**：无法取得可读 PDF 时，依据来源提供的实际摘要；报告只呈现能分析的内容，资料范围保持为摘要。
- **只有题录**：没有可靠摘要或可读正文时，保留题录及尝试过的来源，继续查找其他可靠新论文，不根据标题编造报告。

每次新增检索跳过已分析论文，在限定轮次和候选范围内继续扩展来源与年份。OpenAlex 的访问策略、出版社跨域限制、付费墙、扫描件、损坏文件或网络故障均可能限制可分析资料；达到检索上限后按实际新增成果结束，不生成无来源的替代报告。候选、筛选和来源错误保留在原始记录中。报告中的研究行动为待执行方案；未知样本量和阈值需按原文依据或先导实验确定。

浏览器模式不执行服务器端 `norman-paper-reading` 技能，也不完成原图、表格或公式视觉核验。生成报告不等于完成全部精读；作者结论、分析者推断、建议与未核验内容分别记录。需要完整的来源与视觉核验时，使用高级私人后台，参照[部署说明](DEPLOYMENT.md)或[本机使用方式](LOCAL.md)。

## 密钥、本地资料与删除课题

API 密钥只保存在当前页面内存，不写入 IndexedDB、localStorage、Git 或导出文件。刷新或关闭页面后需要重新填写，重新打开课题不会自动恢复密钥。

未绑定目录时，课题、参考 PDF 提取文字与指纹、论文来源文字、候选、批次检查点和报告保存在当前站点的 IndexedDB。清除站点数据会移除这些草稿。不同浏览器、无痕窗口、在线 Pages 与 `http://127.0.0.1:8095/` 不共用浏览器资料，也不自动同步到私人后台。

支持 File System Access 的浏览器可通过顶部「保存目录」选择目录。系统先在目录内临时准备笔记、证据、离线看板及快照，核对后绑定为正式来源，并尝试清除旧浏览器草稿。浏览器只保存目录授权句柄，不暴露绝对路径；表单中的手填路径不能替代授权。不支持的浏览器需使用支持该能力的 Chrome/Edge 或私人后台，不能声称已写入磁盘。

目录授权失效时需重新选择授权，不自动退回旧草稿。不同来源或内容不同的已有研究库不会自动合并覆盖。生成文件被手动编辑时保存停止并保留原件，先合并批注或选择新目录。目录中的 `index.html` 是离线入口；详细布局与来源二进制边界见[唯一主目录说明](RESEARCH.md#唯一长期主目录)。

首页课题卡提供「删除课题」。确认后删除该课题、批次、范围参考与课题关联；正在分析时须先停止并等待任务结束。共享论文记录和实例编号保留，以免影响其他课题或重复登记。删除不能通过页面撤销，建议先导出需要保留的资料。

JSON 保留报告、来源覆盖、批次原始审计、综合及参考文字；Markdown 与离线 HTML 按有内容才展示的规则生成报告，HTML 提供同样的卡片预览、筛选和点击详情。导出不包含原 PDF 或 API 密钥，属于私人研究备份，公开分享前请检查隐私与论文许可。切换高级私人后台不会自动迁移浏览器课题或合并编号。默认不生成每日 DOCX、ZIP 或完整工作目录副本；需要汇报时手动导出。

## 继续任务与连接问题

任务在当前页面运行。关闭网页后不会继续执行；已发请求仍可能由供应商处理并计费。重新打开同一站点、填写密钥后，可从课题内的批次运行记录手动恢复检查点，恢复可能再次产生 API 用量。

供应商必须允许来自看板网页的跨域请求（CORS）。接口格式兼容或能从服务器调用，不保证浏览器能直连。页面不能绕过供应商或出版社的 CORS 限制；无法直连时可改用已有私人后台，由服务器连接来源和模型。

运行浏览器批次需要 Web Locks，避免多个标签页覆盖研究库；缺少此能力时拒绝启动批次，已存课题仍可查看。HTTP 429 可能涉及额度、消费上限或请求频率，请按提示在供应商控制台核对。超时或请求失败不代表已生成可靠报告，恢复前先查看批次实际保存状态。
