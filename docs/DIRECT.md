# 在在线网页直连模型 API

API 直连适合先检索相关文献，并依据可取得的摘要整理阅读草稿。打开[在线看板](https://jennie35.github.io/paper-workbench/)即可配置，不需要部署私人后台。

## 填写连接信息

1. 打开连接入口，选择默认的「API 直连」。
2. 填写供应商提供的 **HTTPS API 基础地址**。DeepSeek 官方地址为 `https://api.deepseek.com`，不要手动添加 `/chat/completions`。
3. 填写这家供应商的 **API 密钥**，以及当前可用的 **文本模型名称**。密钥不等于模型名，也不是 GitHub 或后台登录口令。
4. 可使用获取模型列表功能选择名称；供应商不提供该接口或浏览器无法读取列表时，从供应商控制台复制准确名称，手动填写。项目不固定某个旧模型名。
5. 创建或打开课题，确认研究范围。每批默认 5 篇，可选 1–20；可生成的草稿取决于候选中实际可取得的摘要。启动前检查数量、模型及将发送的内容，再确认运行。

接口使用兼容的 Chat Completions 请求格式。API 调用由供应商计费；保存当前连接信息不运行论文分析，获取模型列表也不代表已经完成模型分析。检索后的题录、摘要及课题范围会发送到你指定的模型服务。

## 密钥与本地课题库

API 密钥只保存在当前页面内存。项目不会把它写入 IndexedDB、localStorage、Git 或导出记录。刷新、关闭页面后需要重新填写，重新打开课题不会自动恢复密钥。

课题、候选题录、批次检查点和未核验草稿保存在当前浏览器的 IndexedDB 中。这个课题库只属于当前浏览器及站点来源，不是私人后台中的研究库，也不会自动同步到其他设备。不同浏览器、无痕窗口、在线 Pages 与 `http://127.0.0.1:8095/` 不共用这一份数据。清除站点数据会移除本地课题库；需要保留时，使用界面提供的导出功能备份，导出不含 API 密钥。

切换到高级私人后台模式不会自动迁移浏览器课题或合并编号。若要开展全文精读，请在私人后台中创建或选择对应课题，按该模式保存资料。

## 检索与阅读的范围

直连模式通过 Crossref 获取真实学术题录，记录来源及筛选结果，不使用合成示例冒充检索。取得实际摘要后才可生成摘要分析草稿；没有摘要时保留题录和资料缺口，不编造全文内容。

所有直连草稿都应显示为**未核验**，不计入完整精读。摘要通常无法确认样本、对照、统计细节、图表和公式；未知内容应保留缺口，不能把建议写成作者已完成的实验。

浏览器模式不执行服务器端 `norman-paper-reading` 技能，不解析上传的参考 PDF，不获取和逐图核验论文全文，也不生成已核验的完整精读记录。需要 PDF 范围解析、全文身份检查、原图与公式核对时，选择高级私人后台模式，参照[部署说明](DEPLOYMENT.md)或[本机使用方式](LOCAL.md)。

## 继续任务与处理连接问题

任务在当前页面运行。关闭网页或浏览器后不会继续执行后续步骤；已发送请求仍可能由供应商处理并计费，已保存的检查点仍在本地库中。重新打开同一站点、填写 API 密钥后，查看对应课题的批次记录，手动确认恢复。恢复可能再次产生 API 用量。

供应商必须允许来自看板网页的跨域请求（CORS）。即使接口格式兼容或地址能够在服务器上使用，也不保证浏览器能直接调用。若提示浏览器跨域或网络连接失败，先核对 HTTPS 地址和供应商的浏览器访问支持；页面不能绕过供应商的 CORS 限制。无法直连时，可改用已有私人后台，由服务端连接模型 API。

运行浏览器批次需要 Web Locks，以避免多个标签页同时覆盖研究库。不提供此能力时，页面会拒绝启动批次；已有课题仍可查看。已有后台模式用户也可在模型设置中选择「切换为 API 直连」，进入独立的浏览器课题库。

HTTP 429 可能涉及额度、消费上限或请求频率，按错误提示在供应商控制台核对。未识别的响应、超时或连接失败不代表已生成可靠草稿；请先查看批次的实际保存状态，再确认是否恢复。
