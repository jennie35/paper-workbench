# 正文报告、中文资料与关系图谱

GitHub Pages 托管界面；私人后端保存正文并运行任务。推送 GitHub 不会启动后端。原有直连模式与浏览器资料继续保留。

## 日常操作

1. 创建课题、确认中英文检索词，连接私人后台并配置文本模型。视觉模型可选；关键结论依赖图表或公式时，需要可用的视觉模型查看原页。
2. 确认「目标新增 X 篇」。只有取得正文、覆盖科学问题／方法／关键结果且结论有来源定位的新报告计入。摘要只供筛选。
3. 在资料面板补充「这篇论文的正文 PDF」。顶部「范围参考 PDF」只界定范围，不能代替每篇正文。
4. 来源不足时任务等待资料并保留检查点。补充后显式确认继续，不以摘要凑数。
5. 阅读室可更新已有论文正文，保留原记录及修订，补读不计新增。

正文全部分组阅读，不再只发送前60,000字符。扫描页通过服务器Tesseract（chi_sim、chi_tra、eng）识别，原文件、文字、页码和提取方法分别记录。按关键结论选择原页，超预算保留处理中状态，调整预算后继续。图像模型解释未经独立人工复核。

## 中文导入与迁移

课题内「导入题录 / 研究库」接受 RIS、BibTeX、EndNote XML、此前导出的课题JSON。UTF-8或GB18030题录先预览再确认；确认不调用模型。作者或年份不全时保留补核提示。

导入资料面板逐篇添加PDF，选择1–20篇并确认分析。此任务不另检索、不计联网新增。旧记录保留 legacy_id、来源和修订；后端统一编号与原编号映射随记录导出，不覆盖原浏览器库。

无DOI文献允许入库。优先精确来源ID及DOI，再用题名、作者、年份、刊物组合；疑似中英别名不静默合并。首版不包含机构授权的中文数据库接口。

## 图谱

「引用关系」区分直接引用、共同参考文献和共同被引；「主题相似」单独展示本地多语种模型计算的内容相似性。关系保存依据、时间和算法版本，相似不等于科学结论支持。

节点年份对应颜色，有来源的被引次数对应大小；未知不按零处理。初始最多50节点，可展开至200。前序／后续研究仅反映当前取得的关系集合。没有引用数据时保留独立节点，不补造线。

「发现相关论文」仅增加候选题录，不自动生成报告。直连库展示已保存关系；联网扩展和主题计算由后端提供。离线HTML保存图谱快照、依据和报告链接，离线不重新联网计算。

## 部署配置

基础 `docker compose up -d --build` 不要求Norman。容器含PDF解析、渲染与中英OCR；可选技能通过 `compose.norman.yaml` 挂载，实际应用才署名。Linux运行其原生工具仍需兼容桥接。

主题图需设置 `INSTALL_EMBEDDINGS=true` 后重建；模型为 `intfloat/multilingual-e5-small`，默认只读本地缓存，首次允许下载设置 `EMBEDDING_ALLOW_DOWNLOAD=1`。模型缓存位于 `/models`，不进Git；未准备好时明确不可用。

OpenAlex计量正文下载默认禁用（`OPENALEX_CONTENT_DAILY_LIMIT=0`）。配置密钥并设置每天允许尝试次数后启用；公开PDF来源不受此内容预算限制，不自动购买额度。模型调用按供应商计费。

资料接口均需登录，下载限制公网地址、文件大小和超时。正文、图像、模型权重和密钥不进入Pages。

## 验证边界

固定资料及模拟接口测试不证明科学结论正确。部署后的真实验收顺序是一篇中文公开全文、一篇英文公开全文，再验证五篇；核对正文后部、原页、定位、修订及导出一致性。未配置实际服务和模型时不声称已通过真实验收。
