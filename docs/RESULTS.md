# 阅读课题报告与批次记录

首页提供课题入口与删除按钮。点击「进入课题」直接查看该课题的文献报告，页面不再使用独立的「分析批次与结果」导航。「返回课题首页」用于切换课题。

## 报告与批次

课题内提供「最近更新」「全部文献」「精选精读」「下一步研究」四个入口，并支持关键词、主题、日期和优先级筛选。批次用 `B001` 等课题内顺序号及短任务 ID 标识，报告卡片保留所属批次；选择器用于切换批次。日期相同或重复运行时，应连同短任务 ID 区分。

本批摘要显示目标、已生成报告与缺额。生成报告即可打开阅读；无需等原图与公式全部核验才显示文字内容。运行历史、失败原因、未成报告的候选及排除理由折叠保留，可按需展开。

报告详情采用[十一节研究结构](RESEARCH.md#每篇报告的十一节)：题录与阅读范围、简明总结、科学问题与研究主线、分析者流程、分类研究设计、关键设计决策、图表公式核验、证据与局限、精读位置、未来研究启示和行动卡。原文未报告或尚未取得的内容明确列出；作者结果、作者解释、分析者推断与待验证假设分开显示。研究行动包含判断依据、资源前提和停止条件，是待执行方案。

新报告保留分析时的课题条件快照。更换问题、设备或资源后，旧报告不会被改写为在新条件下完成；页面提示需要重新评估适用性。旧记录仍可阅读，缺少的结构明确显示未记录，不自动扩写成新分析。

## 跨论文综合与运行简报

课题内的综合根据已保存报告说明支持、冲突、可能原因与研究判断变化，引用已有行动提出优先验证的 1–3 项，并标明暂缓、补证据或放弃的路线。单篇或不足证据时明确限制，不能为了填满栏目编造冲突；综合不提高原报告的核验等级，也不把优先级当作论文质量排名。

综合在显式启动的分析批次中生成。失败时已保存报告保留，页面提供确认后重试；读取综合、筛选或重新打开课题不调用模型。浏览器综合使用限定长度的报告字段，后台最多比较最近 30 篇；覆盖和未核验边界随结果记录。

运行简报按需展示与导出 Markdown，列出日期、实际新增与累计、每篇概况及原文、值得精读的证据、研究启示、优先行动、保存位置及未完成核验。复用不计新增，批次结束不等于完成原图与公式精读。

## 在线 API 直连

直连从 Crossref 与 OpenAlex 检索真实题录，尝试补充摘要及开放 PDF。实际取得且身份匹配的 PDF 文字可生成「全文文字报告」；没有可读 PDF 时，可根据真实摘要生成「摘要研究报告」。摘要和正文均缺失时只保留题录及缺口，不凭题名编写内容。

文字报告标明来源、实际阅读范围、来源块或页码。PDF 未读页、超过模型上下文的截断内容、原图与公式的视觉核验以及外部 Norman 技能状态分别记录。报告可用于理解资料和规划后续阅读，但不冒充完成全部精读。

参考 PDF 仅界定研究范围，不占本批论文额度。浏览器只保存实际提取的文字与指纹；范围参考不自动变成论文分析记录。详情见[API 直连说明](DIRECT.md)。

任务在当前页面执行，关闭网页后不会继续。重新打开同一站点并填写密钥后，可从运行记录手动恢复检查点；确认后才发起后续模型请求。恢复可能产生 API 用量。未绑定长期目录时，课题与报告为当前站点 IndexedDB 中的草稿；通过「保存目录」授权并核对保存后，以所选目录为正式来源。浏览器无法提供绝对路径，不持久保存原始 PDF 或原图；密钥不随记录保存或导出。目录布局与恢复边界见[研究工作流](RESEARCH.md#唯一长期主目录)。

## 私人后台的核验记录

私人后台会进一步检查全文身份、来源块、原始页面、公式及分析结构。已通过该流程的论文进入实例主台账，使用连续编号；模型核验仍不等于独立人工复核或实验复现。

未通过核验的分析仍可在课题内阅读，详情保留资料缺口、分段笔记与来源定位。取得图片和完成视觉核验分别记录，成功下载或渲染不等于完成精读。

- 缺正文时可在候选详情补传可读 PDF。上传成功后保留文件名和保存时间，不立即增加精读完成数。
- 点击「继续整个批次」前会显示确认信息。恢复处理本批剩余候选，沿用原范围和当前模型配置，可能产生 API 用量；已登记论文不重复新增。
- 原始来源块、已获取 PDF、原图及候选 JSON 由鉴权接口提供，不自动公开到 Pages。
- 课题内可导出报告；私人后台离线导出支持已保存的本地图像。没有正式记录时，不把空库导出声称为完整成果。
- 正式记录可在后台主目录的日期/论文编号视图中查阅笔记和证据；PDF、原图与来源映射引用规范位置，主目录由部署者配置，课题表单不能改写。

后台任务在关闭网页后继续运行。同一实例一次执行一个批次；新分析前检查外部技能、文本与图像能力，预检失败保留具体错误。刷新可同步其他标签页的后台变化；切换课题时清除旧筛选，迟到响应不应覆盖新课题。

## 删除课题

课题首页的「删除课题」只在确认后执行。若课题仍有排队或运行中的任务，先取消并等待任务停止。删除移除该课题、批次、范围参考和课题关联；实例主台账、连续编号与共享论文证据保留，不影响其他课题。需要留档时先导出，页面不提供撤销删除。

保存操作不会清空用户目录、批注或历史来源；发现生成文件被手工修改时停止覆盖并提示处理。默认不生成每日 DOCX、ZIP 或完整 `outputs/work` 副本。
