# 阅读课题报告与批次记录

首页提供课题入口与删除按钮。点击「进入课题」直接查看该课题的文献报告，页面不再使用独立的「分析批次与结果」导航。「返回课题首页」用于切换课题。

## 报告与批次

课题内以「本批」「全部」「研究行动」切换内容。批次用 `B001` 等课题内顺序号及短任务 ID 标识，报告卡片保留所属批次；选择器用于切换批次。日期相同或重复运行时，应连同短任务 ID 区分。

本批摘要显示目标、已生成报告与缺额。生成报告即可打开阅读；无需等原图与公式全部核验才显示文字内容。运行历史、失败原因、未成报告的候选及排除理由折叠保留，可按需展开。

报告详情依次提供简明总结、科学问题、分析者流程示意、研究设计、证据与局限、精读清单、未来研究启示和行动。原文未报告或尚未取得的内容明确列出；研究行动是待执行方案，不能当作作者已完成实验。

## 在线 API 直连

直连从 Crossref 与 OpenAlex 检索真实题录，尝试补充摘要及开放 PDF。实际取得且身份匹配的 PDF 文字可生成「全文文字报告」；没有可读 PDF 时，可根据真实摘要生成「摘要研究报告」。摘要和正文均缺失时只保留题录及缺口，不凭题名编写内容。

文字报告标明来源、实际阅读范围、来源块或页码。PDF 未读页、超过模型上下文的截断内容、原图与公式的视觉核验以及外部 Norman 技能状态分别记录。报告可用于理解资料和规划后续阅读，但不冒充完成全部精读。

参考 PDF 仅界定研究范围，不占本批论文额度。浏览器只保存实际提取的文字与指纹；范围参考不自动变成论文分析记录。详情见[API 直连说明](DIRECT.md)。

任务在当前页面执行，关闭网页后不会继续。重新打开同一站点并填写密钥后，可从运行记录手动恢复检查点；确认后才发起后续模型请求。恢复可能产生 API 用量。课题与报告保存在当前浏览器来源的 IndexedDB，密钥不随记录保存或导出。

## 私人后台的核验记录

私人后台会进一步检查全文身份、来源块、原始页面、公式及分析结构。已通过该流程的论文进入实例主台账，使用连续编号；模型核验仍不等于独立人工复核或实验复现。

未通过核验的分析仍可在课题内阅读，详情保留资料缺口、分段笔记与来源定位。取得图片和完成视觉核验分别记录，成功下载或渲染不等于完成精读。

- 缺正文时可在候选详情补传可读 PDF。上传成功后保留文件名和保存时间，不立即增加精读完成数。
- 点击「继续整个批次」前会显示确认信息。恢复处理本批剩余候选，沿用原范围和当前模型配置，可能产生 API 用量；已登记论文不重复新增。
- 原始来源块、已获取 PDF、原图及候选 JSON 由鉴权接口提供，不自动公开到 Pages。
- 课题内可导出报告；私人后台离线导出支持已保存的本地图像。没有正式记录时，不把空库导出声称为完整成果。

后台任务在关闭网页后继续运行。同一实例一次执行一个批次；新分析前检查外部技能、文本与图像能力，预检失败保留具体错误。刷新可同步其他标签页的后台变化；切换课题时清除旧筛选，迟到响应不应覆盖新课题。

## 删除课题

课题首页的「删除课题」只在确认后执行。若课题仍有排队或运行中的任务，先取消并等待任务停止。删除移除该课题、批次、范围参考和课题关联；实例主台账、连续编号与共享论文证据保留，不影响其他课题。需要留档时先导出，页面不提供撤销删除。
