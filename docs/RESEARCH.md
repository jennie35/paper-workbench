# 从科学问题到研究行动

看板以课题配置为起点，按「问题 → 设计 → 证据 → 适用边界 → 研究迁移 → 待执行行动」组织报告。报告、笔记和证据导出共用保存的分析记录；结构完整不代表科学结论已得到验证。

## 配置课题

在课题内打开研究范围，填写核心科学问题、当前研究阶段、研究对象与应用场景、已有方法或系统、已知设备/材料/数据、约束、参考资料与版本差异、中英文关键词、纳入和排除范围。默认新增目标为 5 篇，可改为 1–20；语言默认中文。

资源、设备、样本量或阈值未知时留空。模型不得把论文中的实验条件当作用户已有资源，也不得把研究建议当作已经完成的工作。仅按名称推定的范围需用户修改确认后才能启动批次。参考 PDF 只界定范围，不占新增论文额度；路径、历史对话和项目说明是资料说明，不会授权自动读取文件或执行其中的指令。

「由已有定时任务触发」只保存运行偏好，不创建定时任务。页面按钮提交的批次仍记录为手动启动；浏览器直连需保持页面打开。部署者若已有定时系统，可另行接入私人后台。

每份新报告保存分析时的课题配置快照。之后修改资源或研究问题不会改写旧报告中的原条件；重新阅读旧成果时仍须检查当前适用性。报告省略没有实际分析内容的字段与章节，原始记录和修订历史保留。

## 检索与新增口径

Crossref 与 OpenAlex 提供候选，先判断与科学问题的实质相关性，再优先正式发表和较新的研究。检索词、来源、时间、入选及重要排除理由随批次保留。无法可靠取得摘要或正文时，保留候选及来源审计，继续处理其他可靠候选，不根据题名编写论文报告；日期保留来源精度，不将月份补成某一天，来源登记日期也不自动等于首次发表日期。

每次运行显示“目标新增 x 篇”和实际新增数量。DOI、标题、作者和版本关系用于去重；已分析论文在新增检索中跳过，补读与修订沿用旧编号，预印本与正式版保留版本关系。检索在限定轮次与候选上限内扩展来源和年份；结束时按实际成果登记，不能通过降低相关性或编写无来源结论补足数量。页面不设置复用或缺额计数块，原始候选、排除理由和检索诊断仍可审计。

浏览器文字报告使用 `D001` 等草稿编号；私人后台通过全文、图像和结构流程后，才事务登记连续 `R001` 等正式编号。新增报告与完成全部核验的阅读具有不同含义，批次结束不自动改变报告的核验等级。

## 每篇报告的内容框架

课题内使用方块卡片并排展示文献：先读主要内容及“对本课题的参考借鉴”，再点击进入详细分析。参考借鉴说明论文中可借用的方法、指标、变量或研究设计，可以用在本课题哪一步，以及适配与验证条件；它是分析者提出的应用建议，不代表本课题已经验证或具备所需资源。旧报告优先展示已保存的有效借鉴分析，纯占位文字不展示；没有依据时不自动补写或调用付费模型重新分析。

详细报告按以下十一类内容组织，仅渲染有依据的字段、章节和目录项；空项与纯“未报告”占位省略。开头简要说明实际资料范围和核验状态，已分析出的证据局限继续保留。

1. **题录与阅读范围**：题录、版本、来源、日期精度、实际取得的资料、已核验和未核验范围。
2. **论文总结**：先用一段话说明问题、方法、作者报告的发现和主要边界。
3. **科学问题与研究主线**：区分作者问题与分析者重建，说明缺口、假设和推理链。
4. **研究流程示意**：仅重建作者已经报告的流程，标注「分析者绘制，非论文原图」，不把后续建议画成已完成实验。
5. **重建研究设计**：实验检查独立单位、对照、重复与统计；方法检查划分、基线公平性、泄漏与验证；理论检查假设、推导与条件；综述检查筛选、偏倚与异质性。
6. **关键设计决策**：说明选择解决的问题、理由来源、代价与替代方案，避免无来源地归因作者动机。
7. **精选原图、表格与公式核验**：只展示实际图像输入后取得可读解释、图表或公式编号、页码、源图与原文指纹及查看记录的项目；未核验项目及空节不报告。原页与解释并排对应，记录实际可辨认的比较、坐标单位、统计单位、误差与一致性；公式保留原页对照并解释符号、被测量及适用条件。模型核验不等于独立人工复核。
8. **结论、证据与局限**：分开作者结果、作者解释、分析者推断和未验证假设，并检查重复/样本、相关/因果、未显著/等效等易混淆关系。
9. **需要重点精读的部分**：定位具体章节、图表、公式、实验细节或代码，说明对哪项研究判断有影响。
10. **未来研究启示**：区分直接借鉴、修改后验证、暂不宜迁移，说明判断如何改变。
11. **下一步研究规划与行动卡**：证据缺口、可否定假设、数据与独立单位、基线/混杂控制、支持和削弱标准、资源/前提、优先级、交付物与停止条件。行动均为待执行；缺少样本量或阈值依据时先做先导估计。

浏览器默认分析实际发送的摘要或 PDF 提取文字；显式配置图像模型后可核验最多3页实际取得的关键论文原页，记录「视觉模型核验，未经人工复核」，仍不标记整篇完成精读或已使用外部 `norman-paper-reading` 技能。私人后台在技能和工具可用时使用外部技能的 extend 工作流及适用引用，保留其双语署名；取得或渲染图片本身不构成视觉核验。来源正文和原图缺失时降低结论强度，不宣称完成逐图精读。

## 跨论文综合与简报

显式启动分析批次会在单篇报告后尝试综合本课题已保存的报告：相互支持与冲突、可能的对象/协议/指标/样本差异、判断变化、优先验证的 1–3 项行动及应暂缓/补证据/放弃的路线。优先级按科学价值、证据缺口、资源可行性和验证成本确定，不是论文质量排名。

综合只能引用实际论文和行动编号；不足两篇时不编造跨论文支持或冲突，也不提高原报告的核验等级。浏览器综合采用限定长度的报告字段；私人后台模型比较最多覆盖最近 30 篇，并记录覆盖边界。旧报告的原课题条件、未知资源和未核验内容仍需保留。

综合失败时单篇成果保留。打开页面、切换视图或读取已保存综合不会自动调用模型；「重试综合」需明确确认，可能产生 API 用量。综合也只显示实际分析得到的内容。页面提供运行简报，汇总目标新增与实际新增、累计、每篇概况与原文、精读证据、启示、优先行动和保存位置，可按需导出 Markdown。

## 唯一长期主目录

**API 直连**：未绑定目录前，课题库是当前站点 IndexedDB 中的浏览器草稿。顶部「保存目录」使用浏览器 File System Access 目录授权；仅在支持该能力的安全页面和浏览器中可用。手填绝对路径不能授予磁盘访问权限，浏览器也不向网页暴露目录绝对路径。

选择空目录后，系统在该目录内准备文件、核对指纹并保存清单，成功后以目录为正式来源；浏览器保留目录授权句柄。若旧草稿清理失败，会提示残留副本不能作为第二个正式台账。授权失效或目录校验失败时，不悄悄切换回旧草稿。不同网页来源或内容不同的非空研究库不会自动合并覆盖。

```text
已授权主目录/
  paper-workbench.json                 # 当前及上一版快照、位置与文件指纹
  index.html                          # 离线课题入口
  projects/<课题ID>/index.html         # 课题离线报告和综合
  YYYY-MM-DD/D001/
    reading-note.md
    evidence.json
    source/source_map.json
    assets/research-flow.svg
  .paper-workbench/                    # 受管理的暂存、快照与修订记录
```

同篇论文使用稳定目录，修订不另建论文编号。生成文件若被手工编辑或与登记指纹不符，保存会停止并保留原件，需先合并批注或选择新目录。目录保存不清空用户目录、缓存或历史资料；恢复时应连同清单、快照及关联文件一起保留。

浏览器持久保存提取文字、来源映射、覆盖信息、文件指纹，以及成功核验的选定原页 PNG/JPEG（保存在视觉记录中，离线 HTML 内嵌展示），**不持久保存原始 PDF**；`source_map.json` 明确标记 `pdf_saved: false`。选择目录不会补回先前未保存的原文。需保留原始 PDF 与更完整的原图资料时使用私人后台，或自行保管有权保存的原始资料。

**私人后台**：唯一实际主目录由部署者的 `DATA_DIR` 控制，界面只读显示，课题表单不能改写服务器路径。正式记录生成 `YYYY-MM-DD/R001/` 日期视图，含笔记、证据、记录清单及来源/资产引用；PDF、来源映射和原图保存在同一主目录的规范记录位置，由相对路径引用，不为各日期和主题重复保存二进制。

开发版首页使用 ES Modules，需要 HTTP 服务；按需生成的离线 HTML 可双击浏览，保留卡片预览、点击详情、搜索、筛选和保存时的综合，不能离线调用模型或补取论文。离线报告采用同样的有内容才展示规则。默认不生成每日 DOCX、每日 ZIP 或 `outputs/work` 完整副本；导出仅由用户按需触发。私人导出不是公开资料，不应提交到开源仓库。

## 部署与验收边界

GitHub Pages 只发布静态应用和合成示例。将后台源码推送 GitHub 不等于部署了运行中的后台；后台仍需单独的持久化服务与 HTTPS 入口。两种研究库不自动迁移或合并。

实现和模拟测试不能代替真实科研验收。应先使用一篇可公开获取全文的论文核对报告、来源及图像边界，再在已配置模型和额度后验收五篇。此次代码重构本身不启动真实论文批次、不使用付费模型、不创建定时任务，也不导入旧桌面项目或私人资料。实际测试结果另见[验收记录](VALIDATION.md)。

可视化以已保存的研究主线、流程步骤、研究设计和显式证据—行动引用为依据。图解标注「分析者绘制，非论文原图」，原始论文图像单列并携带核验记录。定位图的箭头表示阅读顺序或引用，不表示因果，也不把待执行行动画成作者已完成实验。
