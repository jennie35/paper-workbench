## 自动化测试范围

- 登录、错误口令限流、未登录的数据与图片访问、CORS 来源限制。
- API 配置加密、密钥不回显、留空保留原值。
- 课题与范围保存、无效 PDF 与批次数量限制。
- DOI 大小写、标题规范化、版本关系、跨课题复用与连续编号。
- 来源块及证据引用不存在时拒绝完成，原图页码越界时拒绝核验。
- 无全文不计额度、原图失败不登记、缺少技能如实失败。
- 取消保留检查点、完成任务重跑不重复、提交后中断的计数恢复。
- 全篇分析流程使用模拟 API：读取原图请求、据视觉记录修正分析、校验后再完成。
- 更改研究范围不会复用旧的分析草稿；没有依据的行动需要说明原因。
- HTML/Markdown/JSON 导出使用同一分析数据，包含本地图片，署名不重复。
- 原始 HTML、危险链接、流程图脚本注入和导出中非本地自动加载图片的处理。
- 公网地址限制、内部地址与 DNS rebinding 拦截。
- 原生桥接认证、归档越界路径与任意命令拒绝。
