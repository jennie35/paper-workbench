## 参考 PDF 的浏览器处理边界（2026-10-17）

- 每份参考资料最多 50 MB、300 页；同一课题按 SHA-256 文件指纹去重，不把参考文件作为本批论文重复登记。
- 原 PDF 在本机解析，不持久保存或上传；提取文字、页码、文件指纹与未读缺口保存在当前站点的 IndexedDB。加密文件拒绝处理，纯扫描资料需要 OCR，部分无文字页保留缺口。
- 添加参考文件本身不调用模型。模型提取范围时才向所配置的供应商发送实际提取的参考文字，并限制单次总上下文长度；截断与未读内容不能冒充全文覆盖。
- 参考资料文字始终作为数据，不能改变系统指令。提取范围须由用户修改确认；文字提取成功不等于完成论文精读、原图或公式核验。
- JSON、Markdown、HTML 导出包含参考提取文本及缺口，属于私人资料备份；不含原 PDF 或 API 密钥，公开分享前需检查隐私与资料许可。
- 本节记录实现边界；本轮自动化与浏览器验收的实际结果另行补充，不由静态说明推定真实模型分析成功。
