- 原生 Norman 1.4.0：在 Windows 上使用自行生成的测试 PDF，实际运行 version、extract、render、validate，均成功。没有分析私人论文，也没有复制技能文件到本项目。

桌面及手机验收截图保存在本目录。全部使用合成内容，不展示真实研究材料。

## 自动化测试范围

- 登录、错误口令限流、未登录的数据与图片访问、CORS 来源限制。
- API 配置加密、密钥不回显、留空保留原值。
- 课题与范围保存、无效 PDF 与批次数量限制。
- DOI 大小写、标题规范化、版本关系、跨课题复用与连续编号。
- 来源块及证据引用不存在时拒绝完成，原图页码越界时拒绝核验。
- 无全文不计额度、原图失败不登记、缺少技能如实失败。
- 取消保留检查点、完成任务重跑不重复、提交后中断的计数恢复。
- 全篇分析流程使用模拟 API：读取原图请求、据视觉记录修正分析、校验后再完成。
- 更改研究范围不会复用旧的分析草稿；没有依据的行动需要说明原因。
- HTML/Markdown/JSON 导出使用同一分析数据，包含本地图片，署名不重复。
- 原始 HTML、危险链接、流程图脚本注入和导出中非本地自动加载图片的处理。
- 公网地址限制、内部地址与 DNS rebinding 拦截。
- 原生桥接认证、归档越界路径与任意命令拒绝。

## 尚未执行的验收

- 本机没有 Docker、PostgreSQL 或 Redis 服务，未运行 Compose 及真实队列重启恢复；已提供部署配置、健康检查及对应测试路径。
- 没有用户模型 API 密钥，未执行付费模型调用；真实论文的“一篇 → 五篇”端到端分析尚未完成。模拟测试不能代替这一步。
- 未通过公网 HTTPS 部署原生桥接；本次仅实际验证本机原生引擎及桥接的认证/输入防护。
- GitHub Actions 的实际结果和 Pages 是否上线，应以目标仓库中的工作流及访问结果为准，不能由本地测试推定。
- 研究内容需要研究者判断；结构校验、模型视觉读取和接口成功均不证明科学结论正确。

运行测试时有一个 Starlette TestClient 对 httpx 的弃用提示，不影响上述测试结果；后续升级测试客户端时应复核兼容性。
