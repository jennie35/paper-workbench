# 在当前电脑上使用

本机版将前端、API 和任务执行放在同一个 Python 进程中，使用 SQLite 和本地文件保存私人资料，不需要 PostgreSQL、Redis 或 Docker。它用于单人临时试用；公网部署仍使用原来的 Compose 方案。

由维护者安装好项目依赖后，从仓库根目录启动：

```sh
python backend/run_local.py --port 8095
```

浏览器打开 `http://127.0.0.1:8095/`。点击“连接服务”，后台地址填写 `http://127.0.0.1:8095`。首次启动自动生成随机管理员口令，可用下面的命令查看：

```sh
python backend/run_local.py --show-password
```

登录后，首页只展示课题入口。创建课题或点击「进入课题」后，可上传参考 PDF、编辑研究范围，并在课题内的「文献与研究行动」「分析批次与结果」之间切换。点击「返回课题首页」可打开其他课题；分析结果归属于对应课题。

要自动提取范围或运行论文分析，还需在「连接与模型设置」填写可用的模型接口、当前供应商密钥、文本模型和视觉模型。「仅保存配置」不调用模型；可选的「保存并检查接口」会先保存当前填写内容，再实际检查技能和文本、图像能力，可能产生 API 费用。批次启动后会自动预检，无须重复手动检查。模型接口不是私人后台地址，两者分别填写。

同一 API 来源下，密钥留空会保留已保存值；更换供应商地址时必须重新填写对应密钥。修改配置后，旧的检查通过状态会失效，不能据此认为新配置已可用。

本机模式自动寻找本机已安装的外部 Norman 技能，也支持部署者设置 `NORMAN_SKILL_PATH`。不包含第三方技能或授权。

连接 OpenAI 官方 API 时，本机模式会使用启动进程继承的 `HTTPS_PROXY`（HTTP 或 HTTPS 代理），也可显式设置 `OPENAI_HTTP_PROXY`。仅固定官方域名 `api.openai.com` 允许由可信代理解析地址；其他模型服务及论文下载保持公网地址检查和 IP 固定。代理地址仅由部署者设置，不从论文、页面或上传资料读取。生产环境需要显式设置该变量；容器里的 `127.0.0.1` 指容器自身。

数据及本机生成的配置保存在项目 `data/` 目录，已排除 Git 上传。不要删除该目录，也不要提交到公共仓库。重新启动继续使用原来的管理员口令、加密密钥、课题和台账；启动时会恢复未结束批次的检查点。

浏览器关闭后任务继续执行；后台进程停止或电脑关机后服务不可用。再次运行启动命令可恢复。只绑定 `127.0.0.1`，其他电脑不能通过公网 Pages 自动连接到这台电脑。不要使用多个进程同时打开同一个本机数据库。
